# Supply Chain Intelligence Assistant (demo)

Streamlit chat demo for the AI-Powered Supply Chain Intelligence project. A LangGraph agent with LangChain tools answers questions from the inventory policy table, a TF-IDF knowledge-base search and a replenishment simulation.

The policy comparison assumes a lost-sale cost of 25% of unit price (not part of the original dataset). The GROQ_API_KEY is read from Streamlit secrets and is not stored in this repo.

Full project: https://github.com/Shreyashree-Mondal/supply-chain-intelligence
